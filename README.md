# ShoutRunner

Licensed plugin. To install, add the following URL to your Dalamud custom repositories:

```
https://raw.githubusercontent.com/PersephoneAsphodel/shoutrunner-releases/main/pluginmaster.json
```

**How to add:**
1. Open FFXIV with XIVLauncher
2. Click the Dalamud settings icon (or type `/xlsettings`)
3. Go to the **Experimental** tab
4. Paste the URL above into the **Custom Plugin Repositories** field and click **+**
5. Go to the **All Plugins** tab and search for **ShoutRunner**
6. Click Install

A valid license key is required to use the plugin.  
Contact the author to purchase a license.
